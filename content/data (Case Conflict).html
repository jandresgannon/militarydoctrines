File Contents
Metadata (.csv) One row per document: country, year, title, language, type, core-corpus flag. See the codebook.

Search across all columns, or filter a column using the box under its header. 823 documents in total. The PDF link opens the original document; TXT opens the extracted text; CSV downloads the chunked text.

Download your results. The buttons below download whatever the table currently shows: type United States in the search box, for example, and Texts (.zip) returns every US document’s text. The metadata file includes a pdf_url column with a direct link to each document’s PDF.
